# 🔐 Password Generator

A simple and secure **Python GUI application** that generates strong and random passwords based on user preferences.

## 💡 Features

- Generate passwords of custom lengths
- Include letters, digits, and special characters
- User-friendly interface using `tkinter`
- Easy to use for quick, secure password creation
